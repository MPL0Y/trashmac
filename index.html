Small app. One job.

Any app that uses the Trash.

Finder, your code editor, a download manager. TrashMac watches the Trash itself, so it doesn’t matter who sent the file. Permanent deletes skip the Trash, so they skip the show.

Lands on the real Trash.

It asks the Dock where the Trash is, so every flight lands on it, whether your Dock sits at the bottom, left or right.

Stays out of your way.

It lives in the menu bar with no Dock icon, and the animation never blocks a click.

Up and running in a minute.

  1. Download it.

    Open the DMG and drag TrashMac into Applications.

  2. Open it once.

    TrashMac isn’t notarized, so macOS stops the first launch. Go to System Settings → Privacy & Security and click Open Anyway.

  3. Allow Accessibility.

    That’s how it finds the Trash in your Dock. It reads where the Dock’s icons are and nothing else. A test file flies in the moment you allow it. Choose Open at Login from the trash icon in the menu bar to keep it running.

Download for Mac

Or install with Homebrew:

$ brew install --cask mpl0y/tap/trashmac

Or build it yourself.

One script compiles TrashMac for Apple silicon and Intel and packs it into a DMG. You’ll need the Xcode Command Line Tools. Run xcode-select --install if you don’t have them. A copy you build opens without the Gatekeeper step.

Terminal
$ git clone https://github.com/MPL0Y/trashmac.git
$ cd trashmac && ./build.sh
$ open TrashMac.dmg

Questions.

Why does it need Accessibility?

To ask the Dock where the Trash icon is, so every file lands on it. It reads the Dock’s list of items and nothing else.

Why isn’t it notarized?

Notarizing needs a paid Apple developer account. TrashMac is one Swift file you can read on GitHub, or build yourself to skip the warning.

Will it slow my Mac down?

No. It waits for something to land in the Trash, draws for half a second, then goes back to waiting.

Does it start when I log in?

Choose Open at Login from its menu bar icon, and it will be there after every restart.

How do I update it?

Choose Check for Updates from its menu bar icon. If you installed with Homebrew, run brew upgrade trashmac.

How do I remove it?

Turn off Open at Login, choose Quit TrashMac, then drag it from Applications to the Trash. You won’t see this one fly.
